Supervised learning means we train a model using examples where the correct answer is already known.

6. How Gradient Boosting works

Gradient Boosting builds many small trees in sequence. Each new tree tries to improve the mistakes made by the earlier trees.

Main idea: not one big tree at once, but many small steps that keep correcting the model.

Round 1

The first small tree makes an initial prediction.

Tree 1: first guess

Round 2

The next tree focuses on the earlier mistakes.

Tree 2
Corrects some errors from Tree 1

Round 3

Another tree is added to improve the result further.

Tree 3
Corrects more errors

Final model

The final prediction comes from combining the contribution of all small trees.

Final prediction = Tree 1 + Tree 2 + Tree 3 + ...
You can explain it like this: one tree starts, the next tree helps, the next tree improves again, and the final model is the combination.

7. Gradient Boosting parameters used in the notebooks

A parameter is a setting we give to the model before training. It controls how the model learns.

You do not need to memorise every parameter. The main ones to understand are n_estimators, learning_rate and max_depth.

Classification notebook

GradientBoostingClassifier(
    loss='log_loss',
    learning_rate=0.1,
    n_estimators=100,
    subsample=1.0,
    max_depth=3,
    min_samples_split=2,
    min_samples_leaf=1,
    max_features=None,
    random_state=42,
    ccp_alpha=0.0
)

Regression notebook

GradientBoostingRegressor(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=3,
    random_state=42
)

The main parameters

ParameterValue in notebookWhat it meansSimple way to explain it
n_estimators100How many small boosting trees are built.The model gets up to 100 small chances to improve its prediction.
learning_rate0.1How strongly each new tree changes the current prediction.Each tree contributes a small correction rather than making a huge change.
max_depth3How deep each small decision tree is allowed to grow.Each tree stays fairly simple. A depth of 3 means only a few levels of questions.
random_state42Fixes the random choices so the same run can be reproduced.If we run the notebook again, we can get the same random behaviour.

Extra parameters in the classification notebook

ParameterValueMeaning
loss'log_loss'The error function used for classification. The model tries to reduce classification error measured through log loss.
subsample1.0Uses 100% of the training data when building each boosting stage.
min_samples_split2A node needs at least 2 samples before it can be considered for another split.
min_samples_leaf1A final leaf is allowed to contain at least 1 sample.
max_featuresNoneNo feature limit is applied when the tree looks for a split. It can consider all features.
ccp_alpha0.0No cost-complexity pruning is applied to the small trees.
Useful relationship to point out: learning_rate and n_estimators work together. A smaller learning rate means each tree makes a smaller correction, so we often need more trees. A larger learning rate makes stronger corrections, but can make the model learn too aggressively.

9. Evaluation

Classification metrics

Accuracy tells us how many predictions were correct.

90 / 100 = 90%

If the model gets 90 out of 100 examples right, the accuracy is 90%.

Confusion matrix shows where the model is getting classes right or mixing them up.

Regression metrics

MAE means mean absolute error.

Average mistake size

If the price predictions are off by 10k, 20k and 30k, then the MAE is 20k.

For MAE, smaller is better.

Problem typeMain questionTypical metricBetter result
ClassificationDid the model choose the right class?AccuracyHigher
RegressionHow close is the predicted number?MAELower
Quick check

A classifier gets 47 out of 50 predictions correct. What is the accuracy?

Accuracy = 47 ÷ 50 = 0.94 = 94%.
Quick check

A regressor has errors of 5, 7 and 9. What is the MAE?

MAE = (5 + 7 + 9) ÷ 3 = 7.

11. The other five algorithms

While working in pairs, students will run the other five algorithm families below. The aim is to understand the basic idea of each model and compare the results.

Decision Tree

A Decision Tree makes predictions by asking a sequence of simple questions.

Example: “Is petal length greater than 4 cm?” → yes/no → move to the next question → reach a prediction.

Idea: one tree made of decision rules.

Random Forest

A Random Forest uses many Decision Trees instead of relying on only one.

Each tree gives an answer, and the forest combines their answers.

Idea: many trees together usually give a more stable prediction than one tree alone.

Logistic / Linear Regression

Logistic Regression is used for classification. It estimates which class an example is most likely to belong to.

Linear Regression is used for regression. It finds a relationship between the inputs and a numeric target.

Idea: Logistic → category. Linear → number.

k-Nearest Neighbours (KNN)

KNN looks at the most similar training examples nearby.

Classification: nearby examples vote for the class.

Regression: nearby values are combined to predict a number.

Idea: “What happened to examples that look like this one?”

Support Vector Machine (SVM)

For classification, SVM tries to find a boundary that separates different classes as clearly as possible.

For regression, the related model is usually called SVR.

Idea: find the best separating boundary, or a regression line/region that keeps errors controlled.

What to compare while working

When you run each model, focus on the same workflow:

X and y → train/test split → create model → fit → predict → evaluate.

Then compare the metric values and ask: Which model performed better on this dataset?

Quick memory:
Decision Tree = one tree
Random Forest = many trees
Logistic Regression = classify
Linear Regression = predict a number
KNN = look at nearby examples
SVM = find the best boundary

The supplied notebooks contain multiple model cells. If later cells are run, the active model can change. So when explaining Gradient Boosting, make sure the Gradient Boosting model cell has been run before the evaluation you are discussing.

This matters because the evaluation output belongs to whichever model was run most recently.

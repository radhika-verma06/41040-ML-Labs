Generative AI in this lab is easier than it sounds

The first decision

Are we copying an existing example, or creating a new one?

Before AE, VAE or GAN, make this distinction. It prevents most of the confusion in this lab.

Reconstruction = copy the same example

There is a specific input x. The model produces x̂, its attempt to recreate that input.

x → model → x̂

Then compare x̂ with x.

Generation = make a new example

There is no exact target image or point to copy. Start from random hidden values z and create a new sample.

random z → model → new sample

The output should resemble the kind of data the model learned.

Quick check: if I give a model one exact point and ask it to recreate that point, is that reconstruction or generation?
Reconstruction. A specific input already exists and the output is compared with that same input.
Meet the three models

AE, VAE and GAN in one sentence each

Do not start with formulas. Start with the job each model is doing.

AE • Autoencoder

Job: recreate an input.

It sends the input through an encoder, stores a hidden representation, then uses a decoder to rebuild the input.

input → encoder → hidden → decoder → copy

VAE • Variational Autoencoder

Job: learn a smooth hidden space that can also generate new examples.

Instead of one fixed hidden code, it learns a distribution and samples from it.

input → μ, σ → sample z → decoder

GAN • Generative Adversarial Network

Job: make new samples that look real.

A generator makes samples while a discriminator checks whether they look real or fake.

maker G ↔ checker D

Task 1 • Autoencoder

AE: “take this point and try to give me the same point back”

That is the whole AE idea here. The encoder changes the two input numbers into hidden numbers. The decoder changes the hidden numbers back into two output numbers. Training keeps adjusting the network until the output is close to the original input.

🪞

Think of the AE as a learned mirror

The mirror is not simply copying pixels or coordinates directly. It first passes the input through a hidden representation, then rebuilds it. A good reconstruction should land close to the original.

What the model sees

Each training example is only two numbers: an x-coordinate and a y-coordinate.

(x, y) → encoder → latent → decoder → (x̂, ŷ)

The hat simply means “the model's reconstructed version”.

How does it know whether the copy is good?

The notebook uses MSELoss. In plain English: compare the original numbers with the reconstructed numbers. Small difference = small loss. Large difference = large loss.

0.18

The most important line

loss = MSE(reconstructed, data)

The target is the original data itself. That is the central reconstruction idea.

Only the code you need to recogniseDataReconstruction.ipynb
reconstructed = autoencoder(data)

loss.backward()
optimizer.step()

Measure errorMSE(reconstructed, data) compares the copy with the original.
Improvebackward() + step() adjust weights to reduce the loss next time.
Important notebook detail: the latent vector here has 4 values while the original point has 2 values. So do not describe this exact example as “making the input numerically smaller”. The safe explanation is: encoder → latent representation → decoder → reconstruction.
Task 2 • GAN on spiral data

GAN: one model makes samples, the other model checks them

A GAN is easiest to understand as a repeated game. The generator (G) is the maker. The discriminator (D) is the checker. D learns what real spiral points look like; G learns how to make points that D is more likely to accept as real.

🎨

Maker vs checker

G starts with random numbers and makes a point. D sees real points and generated points and learns the difference. Then G gets another turn and improves. Repeating this is the adversarial training process.

Discriminator update

Real samples are labelled 1. Generated samples are labelled 0. D learns to separate them.

Generator update

G produces a fresh fake sample, but its loss compares D's output with real labels (1). G therefore learns to create samples that D is more likely to accept as real.

The key idea in codeDataReconstruction.ipynb
# train discriminator
loss_discriminator = loss_function(output_discriminator, all_samples_labels)
loss_discriminator.backward()
optimizer_discriminator.step()

# train generator
loss_generator = loss_function(output_discriminator_generated, real_samples_labels)
loss_generator.backward()
optimizer_generator.step()
Do not let the notebook title confuse you: this GAN path is listed under the reconstruction activity, but the generator receives random 2-D noise. It does not take each original spiral point and reproduce that same point one-to-one. It learns to create a similar overall distribution of points.
Task 3 • Variational Autoencoder

VAE: an autoencoder with a “neighbourhood” in hidden space

A normal AE gives a hidden representation. A VAE makes that idea more flexible: instead of saying “the hidden value is exactly here”, it learns a centre and a spread. It can then sample a nearby hidden value z and decode it.

📍

Fixed address vs neighbourhood

AE is like giving one hidden address. VAE is like learning a neighbourhood around an address. Because nearby places are meaningful, we can sample a new place in that hidden space and ask the decoder to create a new image.

Why make the latent space random?

Because after training, we want to pick a new random location in latent space and decode it into a new image.

image → μ, logvar → sample z → decoder → image
Interact: build one latent value
z = μ + ε × σ

ε has not been sampled yet.

Reparameterisation in plain English: first learn the centre μ and spread σ. Then draw one random value ε and calculate z = μ + ε × σ. The random choice is separated into ε, so the rest of the network can still be trained with backpropagation.

The notebook actually uses a 10-dimensional latent space

Loss part 1: BCE

Checks how well the reconstructed pixels match the input pixels.

reconstruction quality

Loss part 2: KL divergence

Encourages the learned latent distributions to stay close to the standard normal distribution used for random sampling.

latent space stays sampleable
VAE loss = BCE + KL divergence
Core VAE codeImageGeneration.ipynb
mu, logvar = self.encode(x.view(-1, 28*28))
z = self.reparameterize(mu, logvar)
x_reconstructed = self.decode(z)

KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
return BCE + KLD

One-pass recap

The whole lab as one natural explanation

This section is deliberately written as continuous, plain-language explanation. It can be read from top to bottom, or used as a final revision pass.

0 / 7
Generative AI in this lab begins with two jobs. Sometimes we already have an input and want the model to recreate it. That is reconstruction. Other times we want the model to create a new sample after learning what the data looks like. That is generation.
The autoencoder handles the clearest reconstruction example. Each spiral point has two numbers, x and y. The encoder turns those numbers into a hidden representation. The decoder turns that hidden representation back into two numbers. The reconstructed point is compared with the original point using MSE, and training adjusts the network so that this difference becomes smaller.
The GAN uses a different idea. It has a generator and a discriminator. The generator begins with random numbers and makes a sample. The discriminator sees real samples and generated samples and learns to distinguish them. Then the generator learns to make samples that the discriminator is more likely to accept as real. The two models improve by being trained in turns.
In the spiral GAN notebook path, the generator is not copying each original point. It starts from random two-dimensional noise and tries to produce a set of points that follows a similar overall spiral distribution. That is why the output should be interpreted as distribution learning rather than one-to-one reconstruction.
The VAE begins with the autoencoder idea but changes the hidden space. Instead of one fixed hidden code, the encoder learns a mean and a variance. A latent value z is sampled from that learned distribution and passed to the decoder. The reconstruction part of the loss keeps the output related to the input, while KL divergence keeps the hidden space close enough to a standard normal distribution that we can sample from it later.
After the VAE is trained, generation becomes simple. We sample new latent vectors from a normal distribution and send them directly to the decoder. The decoder turns those unseen latent values into new digit-like images. The image GAN also generates new digits, but it does so through the generator-versus-discriminator game rather than through an encoder and decoder.
The easiest comparison is therefore this: AE is encoder plus decoder for reconstruction. VAE is encoder plus a sampleable latent distribution plus decoder, which supports generation. GAN is generator plus discriminator, where the generator learns by trying to fool the discriminator.
